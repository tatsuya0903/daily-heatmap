## 境界条件

- 0件は独立したレベル0。正の件数は最大7段階。境界は最大6個で、2以上の安全整数・厳密な昇順。
- Linearは`min + ceil((max-min+1)*k/7)`の中間演算をすべてBigIntで行う。範囲外と重複を除去する。
- Quantileは0件を除外し、0-basedの`sorted[ceil(n*k/7)]`を使用する。添字がn以上の候補、最小値以下、重複を除去する。同値は分割しない。
- Logはlog1p／expm1の候補を、元件数から求めたBigIntの7乗比較で検証する。候補がずれていれば二分探索で数学的な切り上げを確定する。Number単独の`ceilLogBoundary`は許容幅0で、表現値をそのまま切り上げる。
- 全0・正の全同値では自動3方式だけ空境界になる。固定プリセットとカスタムは定義を維持する。
- カスタムは6個の半角10進整数を文字列から検証。空欄・小数・負数・指数表記・重複・降順・範囲外を拒否する。
- 境界数0〜6でも全8色を表示し、定義のない高レベルは「未使用（範囲なし）」とする。
- 確定済みの動的境界をJSON経由で再利用しても、再生成せず同じ分類を得る単体テストを追加。URL Codecは実装していない。

## PR #14 レビュー修正：Logの丸め

値に比例する旧epsilon許容幅を撤去した。`ceilLogBoundary(10^15 + 0.25)`は`10^15+1`となり、0.75の場合も同じく正しく切り上げる。単独のNumberから「計算誤差」と「正当な小数」は判別できないため、整数直上の微小値もMath.ceilで切り上げ、許容幅は0とする。

境界生成では、SPECの実数境界xに対する等価式を使う。

```text
(x+1)^7 = (min+1)^(7-k) * (max+1)^k = target
ceil(x) = 最小の整数bで (b+1)^7 >= target を満たすもの
```

log1p／expm1から得た候補bを、`b^7 < target <= (b+1)^7`で検証する。満たさない場合だけ、候補を使って探索区間を狭め、BigIntで二分探索する。整数境界にぴったり一致する場合も正しく扱い、epsilonによる曖昧な補正範囲を設けない。

- min/maxは安全整数として検証済みで、`+1`から7乗までBigIntで行う。比較値は最大372ビット、二分探索は最大53回。新しい依存パッケージは不要。
- 100兆〜200兆の2番目の境界は`121901365420448`。実数値は約`121901365420447.588960015561237894...`。6番目も旧近似計算の誤差を補正し、`181144732852782`となる。
- `[MAX_SAFE_INTEGER-10, MAX_SAFE_INTEGER]`ではNumberの対数の差が消えていたが、6境界を正しく生成する。
- 既存のLog固定期待値はすべて維持する。旧単体テストの「整数7の直上も7へ戻す」期待値だけは8へ変更する。単独のNumberには誤差の由来を示す情報がなく、この入力は厳密に7より大きいため。
- Python標準Decimalのln／expを80桁・120桁で独立に計算し、非整数の固定参照値が一致することを確認した。さらに固定seedで作った240分布（広い範囲120・最大安全整数付近の狭い範囲120）を140桁のDecimal計算と比較し、不一致0件。
- 理論上整数になる例は、高精度ln／expでも直上・直下の丸めが残るため、`min+1=10^12`、`max+1=128*10^12`から`x=10^12*2^k-1`を代数的に導いてテストする。

参照値の計算は、Decimalの精度を80または120に設定し、`a=Decimal(min+1).ln()`、`b=Decimal(max+1).ln()`、`((a+(b-a)*k/7).exp()-1)`をROUND_CEILINGで整数化した。240分布の比較では精度140を使用した。固定seedは570421、64ビットLCG（乗数6364136223846793005、加数1442695040888963407）で正の安全整数の組を生成し、各回にMAX_SAFE_INTEGER直下の幅10の組も加えた。

残る制約：安全整数の元件数を受け取る現在のLog境界生成は、上記の等価な整数比較で数学的な切り上げを確定できる。一方、任意のNumberを直接受け取る`ceilLogBoundary`は、Number化する前の情報を復元できない。例えばMAX_SAFE_INTEGER-1に0.25を加えると、関数を呼ぶ前に小数が消える。範囲外の件数や小数件数への対応は追加していない。
